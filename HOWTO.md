# Okta Admin — how to use

1. **Pick an org** with the environment selector at the top.
2. **Find apps** with the search box and the type / status filters.
3. **Select rows**, then use the action bar:
   - **Activate / Deactivate** — skips apps already in the target state.
   - **Assign policy** / **Add or remove routing rule** — active apps only.
   - **Clear Everyone group** — removes the built-in Everyone group and opens a progress page
     that tracks Okta's background clean-up of the resulting assignments.
4. **Per-row edits** — rename, admin note, dashboard visibility.
5. **Action log** — every write is listed on the Logs page.

Writes go straight to Okta. Try changes on a non-production org first.
